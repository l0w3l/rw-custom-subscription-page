## Remnawave Subscription Page

Learn more about Remnawave [here](https://docs.rw/).

This fork supports merging active subscriptions by Telegram ID for Xray and Mihomo.
Enable `TELEGRAM_SUBSCRIPTION_MERGE_ENABLED=true`; see [configuration, priority and supported formats](docs/telegram-subscription-merge.md).

Docker image: `1owe1/rw-custom-subscription-page`. See [publishing and deployment](docs/docker-publishing.md).
